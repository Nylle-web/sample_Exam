What is the Backend?
The backend is the "server-side" of a web application. Unlike the frontend (what users see and interact with in their browser), the backend runs on a remote server and handles the behind-the-scenes logic, database management, and communication between systems.

Core Components:

The Server: Listens for incoming HTTP requests (like GET or POST) sent by the client/frontend.

Application Logic (Node.js & Express): Processes the incoming requests, runs security checks, executes business rules, and determines what data to send back.

The Database: Securely stores permanent application data (such as user accounts, posts, or product lists) using systems like MongoDB, PostgreSQL, or MySQL.
